# Армонікс · Бот обліку витрат

## Швидкий старт

### 1. Отримати токени
- Telegram: @BotFather → /newbot → скопіювати токен
- Anthropic: anthropic.com/account/keys → Create Key

### 2. Встановити залежності
```bash
pip install -r requirements.txt
```

### 3. Задати змінні середовища
```bash
export TG_TOKEN="ваш_токен"
export ANTHROPIC_API_KEY="ваш_ключ"
```

### 4. Запустити
```bash
python bot.py
```

## Деплой на Railway
1. Завантажити папку на GitHub
2. Зайти на railway.app → New Project → Deploy from GitHub
3. В Settings → Variables додати TG_TOKEN і ANTHROPIC_API_KEY
4. Deploy ✅

## Команди бота
- `/баланс` — залишок готівки та рахунку
- `/звіт` — витрати по категоріях за місяць
- `/пдв` — ПДВ кредит накопичений
- `/квитанція N` — повернути фото квитанції #N
- `/допомога` — підказка

## Введення витрат
Просто пишіть текстом:
- `400 фарба готівка без ПДВ`
- `12000 фанера карткою з ПДВ Епіцентр`
- `бюджет готівка 100000 рахунок 250000`

Або надсилайте фото квитанції — бот зчитає автоматично.
